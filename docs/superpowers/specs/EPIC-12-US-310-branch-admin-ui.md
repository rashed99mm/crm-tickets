# US-310 — Branch Administration UI

## Problem
Branch administration has no sufficiently defined product behavior or screen contract.

## Assumptions
- A1: OQ-5 and the branch data model are approved first.

## Out of scope
Implementation before the mini-spec is approved.

## Acceptance Criteria
- AC-310.1: A mini-spec defines actors, route, fields, validation, active state, and permissions.
- AC-310.2: The approved UI supports only the defined branch lifecycle.

## Design
This story begins with a mini-spec/ADR, then API/UI implementation tasks are generated from the approved contract. Original story: `US-310` story file / branch administration gap.
